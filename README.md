Отчет о Проделанной Работе: Проект "Библиотека Скоринговой Модели"

1. Цель Проекта:

Разработать Python-библиотеку для предсказания кредитного риска клиента банка.
Реализовать библиотеку с использованием принципов ООП.
Создать собственную модель машинного обучения (Логистическая регрессия) с L2-регуляризацией.
Реализовать модуль оптимизации (Градиентный спуск).
Включить модули для предобработки данных, расчета метрик качества и визуализации результатов.
Обеспечить возможность обучения модели на исторических данных (train-scoring.csv) и применения к новым данным.
Использовать систему контроля версий Git и разместить проект на GitHub.
2. Выполненные Задачи и Реализованные Компоненты:

Настройка Окружения и Инструментов:

Проверена и/или установлена необходимая версия Python.
Настроено и активировано виртуальное окружение (venv) для изоляции зависимостей.
Установлены необходимые библиотеки (numpy, pandas, scikit-learn, matplotlib, seaborn) через менеджер пакетов pip и файл requirements.txt.
Инициализирован локальный Git-репозиторий (git init).
Настроен файл .gitignore для исключения ненужных файлов (окружения venv, кэша и т.д.).

Структура Проекта:

Создана модульная структура проекта в соответствии с заданием:
Пакет credit_scoring/ с подмодулями:
models/ (для моделей)
optim/ (для оптимизаторов)
preprocessing/ (для предобработки)
metrics/ (для метрик)
Основные скрипты: train.py, predict.py.
Файлы конфигурации и данных: config.json, data/.
Файлы документации и зависимостей: README.md, requirements.txt.
Добавлены файлы __init__.py для корректной работы пакетов.
Реализация Библиотеки (credit_scoring/):

models/base_model.py: Создан абстрактный базовый класс BaseModel с абстрактными методами fit, predict, predict_proba, определяющий интерфейс для всех моделей.
preprocessing/transformers.py: Реализован класс DataTransformer, использующий Pipeline и ColumnTransformer из scikit-learn для:
Заполнения пропусков (SimpleImputer - медиана для чисел, мода для категорий).
Масштабирования числовых признаков (StandardScaler).
Кодирования категориальных признаков (OneHotEncoder).
Класс включает методы fit, transform, fit_transform и get_feature_names.
metrics/metrics.py: Реализованы функции для расчета ключевых метрик (accuracy_score, precision_score, recall_score, f1_score) и обертки для roc_auc_score, roc_curve из scikit-learn. Файл __init__.py в пакете metrics обновлен для удобного импорта.
optim/optimizers.py: Реализован класс GradientDescentOptimizer с методом step, выполняющим один шаг обновления весов на основе градиента и скорости обучения.
models/logistic_model.py: Реализован класс LogisticModel, наследующийся от BaseModel:
Поддерживает L2-регуляризацию.
Использует GradientDescentOptimizer (через learning_rate).
Реализованы методы fit (с циклом градиентного спуска, расчетом потерь, логированием и ранней остановкой), predict (с порогом), predict_proba.
Включены вспомогательные методы для добавления константы, расчета сигмоиды, стоимости и градиента (с учетом L2).
Добавлены методы save_model и load_model для сохранения/загрузки весов модели.
Конфигурация (config.json):

Создан файл config.json для управления гиперпараметрами модели (learning_rate, iterations, lambda_reg), параметрами предобработки (списки числовых/категориальных колонок, имя целевой колонки), параметрами обучения (путь к данным, размер тестовой выборки, кол-во фолдов CV) и путями для вывода результатов (модель, трансформер, графики, лог).
Файл был успешно настроен для работы с датасетом train-scoring.csv.
Обучение Модели (train.py):

Скрипт реализует полный пайплайн обучения:
Загрузка конфигурации и данных (pandas.read_csv).
Настройка логирования (logging).
Разделение данных на обучающую и тестовую выборки (train_test_split со стратификацией).
Предобработка данных с использованием DataTransformer (обучение на train, применение к train/test).
Проведение k-fold кросс-валидации (StratifiedKFold) с расчетом и логированием средних метрик.
Обучение финальной модели на всей обучающей выборке.
Оценка финальной модели на тестовой выборке с расчетом и логированием всех метрик.
Генерация и сохранение визуализаций: кривая обучения (потери), ROC-кривая, матрица ошибок (matplotlib, seaborn).
Сохранение обученных DataTransformer и LogisticModel в файлы (pickle).
Предсказание (predict.py):

Скрипт позволяет использовать обученную модель:
Принимает аргументы командной строки (argparse) для путей к входным данным, модели, трансформеру и выходному файлу.
Загружает сохраненные модель и трансформер.
Загружает новые данные (pandas.read_csv).
Применяет к ним загруженный трансформер (transform).
Делает предсказания (predict или predict_proba).
Сохраняет результаты в CSV или выводит в консоль.
Включает опциональную визуализацию (гистограмму вероятностей).

Создана работоспособная структура Python-пакета для кредитного скоринга.
Реализован полный цикл от предобработки данных до обучения, оценки и предсказания с использованием собственной модели логистической регрессии.
Скрипт train.py успешно выполняется на предоставленных данных train-scoring.csv, генерирует артефакты (модель, трансформер) и визуализации.
